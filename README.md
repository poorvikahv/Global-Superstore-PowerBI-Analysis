# Global Superstore -- Power BI Business Analytics Dashboard

An intermediate-level business analytics portfolio project built with
Microsoft Power BI, Power Query, and DAX.

## Project Overview

This project explores Global Superstore retail transactions to
understand sales, profitability, customer segments, product performance,
regional results, shipping, and returns.

## Objectives

-   Track sales, profit, order volume, customers, and profit margin.
-   Compare trends over time.
-   Analyze product and category performance.
-   Explore regional and market performance.
-   Review shipping and returned orders.
-   Communicate findings through interactive report pages.

## Tools

-   Microsoft Power BI Desktop
-   Power Query
-   DAX
-   Microsoft Excel

## Dashboard Pages

1.  Executive Overview
2.  Sales & Product Analysis
3.  Regional Analysis
4.  Operations & Returns
